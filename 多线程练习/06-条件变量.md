# 第 6 章：条件变量

std::condition_variable 类没有成员变量，有成员函数：

+void wait(unique_lock<mutex>& __lock);  // 为什么 wait() 需要一个 unique_lock 作为参数，因为要保证多个线程被notify时，同一时刻只有一个线程能够被启动。 wait() 的过程中会暂时 unlock() 这个锁。

+void notify_one() noexcept;  // 会唤醒所有wait线程中的一个。

+void notify_all() noexcept;  // 会以唤醒所有wait线程。

NOTE:

std::condition_variable 仅仅支持 std::unique_lock<std::mutex> 作为 wait 的参数，如果需要用其他类型的 mutex 锁，可以用 std::condition_variable_any。

std::condition_variable还有 wait_for() 和 wait_until() 函数，分别接受 chrono 时间段和时间点作为参数。详见：https://en.cppreference.com/w/cpp/thread/condition_variable/wait_for。

```cpp
condition_variable(const condition_variable&) = delete;
condition_variable& operator=(const condition_variable&) = delete;
void notify_one() noexcept;
void notify_all() noexcept;
void wait(std::unique_lock<std::mutex>& lock);
```


```cpp
#include <iostream>
#include <thread>
#include <mutex>
#include <condition_variable>

int main()
{
    std::condition_variable condvar;  // 创建一个条件变量
    std::mutex mtx;
    
    std::thread thread1([&] {
    	   std::unique_lock unilock(mtx);  // 创建一个std::unique_lock对象，为std::condition_variable对象调用wait做准备
       condvar.wait(unilock);  // 让本线程陷入等待状态，wait过程中mutex对象会暂时处于unlock状态，直到另一个线程notify了条件变量。
       
	   std::cout << "do something...\n";
	   // mtx处于lock状态
       std::cout << "thread1 weak.\n";
    });
    
    std::this_thread::sleep_for(std::chrono::seconds(1));
    
std::cout << "will notify condition variable\n";
// mtx处于unlock状态
    condvar.notify_one();  // 在主线程中唤醒陷入等待的那个线程
    
    thread1.join();
    return 0;
// will notify condition variable
// do something...
    // thread1 weak.
}
```

对比std::condition_variable对象.notify_one() 与 notify_all()。


```cpp
#include <iostream>
#include <thread>
#include <mutex>
#include <condition_variable>

int main()
{
    std::condition_variable condvar;  // 创建一个条件变量
    std::mutex mtx;

    std::thread thread2([&] {
       std::unique_lock unilock(mtx);
       condvar.wait(unilock);
    
       std::cout << "thread2 do something...\n";
       std::cout << "thread2 weak.\n";
    });

    std::thread thread1([&] {
       std::unique_lock unilock(mtx); 
       condvar.wait(unilock); 
    
       std::cout << "thread1 do something...\n";
       std::cout << "thread1 weak.\n";
});

std::thread thread3([&] {
       std::unique_lock unilock(mtx);
       condvar.wait(unilock);
    
       std::cout << "thread3 do something...\n";
       std::cout << "thread3 weak.\n";
    });
    
    std::this_thread::sleep_for(std::chrono::seconds(1));
    std::cout << "will notify one\n";
    condvar.notify_one();
    
    std::this_thread::sleep_for(std::chrono::seconds(1));
    std::cout << "\nwill notify all\n";
    condvar.notify_all();

    thread1.join();
    thread2.join();
    thread3.join();
return 0;
// will notify one
// thread2 do something...
// thread2 weak.
//
// will notify all
// thread3 do something...
// thread3 weak.
// thread1 do something...
// thread1 weak. // 2->1->3顺序是随机的
}
```
