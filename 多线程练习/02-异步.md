# 第 2 章：异步

“同步”：需要等子线程的结果返回才能继续运行。

“异步”：不需要等子线程的结果返回就可以继续运行。

异步：std::async

std::async 接受一个带返回值的 lambda，std::async会创建一个线程来执行lambda 的函数体download()，自身返回一个 std::future 对象。

接下来你可以在 main 里面做一些别的事情, 比如与前台交互interact()，download 会持续在后台悄悄运行。

最后调用 std::future 的 get() 方法，如果此时 download() 还没完成，会等待 download() 完成，并获取 download() 的返回值。


```cpp
#include <iostream>
#include <string>
#include <thread>
#include <future>
int download(std::string file) {
    for (int i = 0; i < 10; i++) {
        std::cout << "Downloading " << file
                  << " (" << i * 10 << "%)..." << std::endl;
        std::this_thread::sleep_for(std::chrono::milliseconds(1000));
    }
    std::cout << "Download complete: " << file << std::endl;
    return 404;
}

void interact() {
    std::string name;
    std::cin >> name;
    std::cout << "Hi, " << name << std::endl;
}

int main() {
    std::future<int> fret = std::async([&] {
        return download("hello.zip"); 
});
    interact();  // 与前台交互,与此同时download()在后台悄悄运行。
    int ret = fret.get();  // 如果执行到这一句时，download()还没有完成，会等待download()完成，并获取download()的返回值。
    std::cout << "Download result: " << ret << std::endl;
    return 0;
}
```

显式等待：std::future对象.wait()

除了 get() 会等待子线程执行完毕外，wait() 也可以等待子线程执行完，但是不会返回其值。


```cpp
int main()
{
    std::future<int> fret = std::async([&]{
        return download("hello.zip");
    });
    
    interact();
    
    fret.wait();  //等待子线程执行完，但是不会返回其值
    std::cout << "wait() has return." << std::endl;

    return 0;
}
```

等待一段时间：wait_for()

wait()：只要std::future对象所绑定的线程没有执行完，就会无限等下去。

而 wait_for() 则可以指定一个最长等待时间段，用 chrono 里的类表示单位。他会返回一个std::future_status。

如果线程在指定时间段内没有执行完毕，则放弃等待，返回 std::future_status::timeout。

如果线程在指定的时间段内执行完毕，则认为等待成功，返回 std::future_status::ready。

同理还有 wait_until() 其参数是一个时间点。


```cpp
int main()
{
    std::future<int> fret = std::async([&]{
        return download("hello.zip");
    });
    
    interact();
    
    while (true)
    {
        cout << "Waiting for download() complete ..." << endl;

        std::future_status stat = fret.wait_for(std::chrono::milliseconds(1000));
        
        if (stat == std::future_status::ready)
        {
            cout << "future_status::ready." << endl;
            break;
        }
        if (stat == std::future_status::timeout)
        {
            cout << "future_status::timeout" << endl;
        }
    }
    
    int ret = fret.get();
    cout << "Download result: " << ret << endl;

    return 0;
}
```

另一种用法：std::launch::deferred 做参数

std::async 的第一个参数可以设为 std::launch::deferred，这时不会创建一个线程来执行download()，他只会把 lambda 函数体内的运算推迟到 future 的 get() 被调用时。也就是 main 中的 interact()计算完毕后。

这种写法，download()的执行仍在主线程中，他只是函数式编程范式意义上的异步，而不涉及到真正的多线程。可以用这个实现惰性求值（lazy evaluation）之类。


```cpp
int main()
{
    std::future<int> fret = std::async(std::launch::deferred, [&]{
        return download("hello.zip");
    });
    
    interact();
    
    int ret = fret.get();
    cout << "Download result: " << ret << endl;

    return 0;
}
```

std::async 的底层实现：std::promise

如果不想让 std::async 帮你自动创建线程，想要手动创建线程，可以直接用 std::promise。

然后在线程返回的时候，用 set_value() 设置返回值。

在主线程里，用 get_future() 获取其 std::future 对象，

进一步 get() 可以等待并获取线程返回值。


```cpp
int main()
{
    // std::promise 对象可以保存某一类型 T 的值，该值可被 future 对象读取（可能在另外一个线程中）
    std::promise<int> prom;
    std::thread th1([&] {
        int ret = download("hello.zip");
        prom.set_value(ret);  // 设置共享状态的值
    });
    
    // 与 future 关联
    std::future<int> fret = prom.get_future();
    
    interact();  // 与前台交互

    // 通过 get_future 来获取与该 std:: promise 对象 "prom" 相关联的 std::future 对象 "ret"
    int ret = fret.get();
    cout << "download result: " << ret << endl;
    
    return 0; 
}
```
